# Party-Management-System-Using-Node.js

## 📌 Project Description

The **Farewell Party Management System** is a dynamic web application designed to help junior students seamlessly organize a farewell event for their senior counterparts. The system supports collaborative planning, teacher involvement, attendee management, task assignment, budget tracking, and event coordination.

---

## 🎯 Features

### 🧑‍🎓 Student Module
- **Registration & Login**: New/returning students can register with personal details and dietary preferences.
- **Menu Suggestions**: Suggest and vote for dinner menu items.
- **Performance Proposals**: Propose performances and vote for your favorites.

### 👨‍🏫 Teacher Module
- **Teacher Registration**: Teachers can register and mention accompanying family members (complimentary entry).

### 🧰 Organizer Module
- **Task Assignment**: Allocate and track tasks for volunteers.
- **Attendance Management**: Record and report student/teacher/family attendance.
- **Budget Tracking**: Track expenses for venue, catering, and decorations with alerts for budget thresholds.
- **Dashboard Views**: Role-based dashboards for updates, announcements, and task progress.
- **Invitation Management**: Design and distribute invites.

---

## 🧪 Role-Based Use Cases

- **Authentication**: Login system with role-specific dashboards.
- **Dinner Menu Management**: Add, edit, remove, and vote on menu items with budget constraints.
- **Performance Management**: Approve/reject proposals, schedule slots, and rehearsals.
- **Update Broadcasting**: Announcements and task updates.
- **Invitation Team**: Create and distribute visual invites.
- **Budget Monitoring**: Track, update, and alert based on expenses using triggers and stored procedures.
- **Task Managers**: Create, assign, and monitor tasks for each sub-team.
